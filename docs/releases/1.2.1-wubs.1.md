# Waypoint 1.2.1-wubs.1

Restores the Windows compatibility components omitted from the previous local
WoW-focused release. Available Games is the single place to install games.

Windows installations identify their graphics backend: DXMT/Wine for Heroes
of the Storm, D3DMetal/Wine for Overwatch and Diablo. Windows preview titles
retain their Preview label. Native macOS installations retain their usual names.

Wine downloads on first use from the creator's pinned distribution; graphics
components retain the existing licence and verified-download flow. Existing
installation directories, saved accounts and game preferences are preserved.
Host and Rosetta requirements still control which Windows titles are offered.

Apple silicon only. Locally ad-hoc signed, not notarized; self-update disabled.
Packaging and automated checks do not establish Windows gameplay compatibility.
