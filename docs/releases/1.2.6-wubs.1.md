# Waypoint 1.2.6-wubs.1

Adds shared sign-in for Hearthstone and Diablo IV using an existing saved WoW
login on the same Battle.net identity (Americas). Existing saved target-game
logins are reused first. For a supported game without its own saved ticket,
Waypoint obtains fresh target authorization without another sign-in page.
Generated tickets are not cached in the token vault because their lifetime
has not been measured; normal native/Windows launch handoffs still apply.

Without a saved WoW source, in other regions, or for other titles, the existing
direct sign-in flow remains available. Explicit Sign In Again and Play uses
the normal direct-login flow. A failed shared exchange stops with an explanation;
it does not delete saved authorization or silently switch accounts. Close
Blizzard games on other devices before shared authorization; only local WoW
can be detected automatically.

Hearthstone passed a real launch without another login. Diablo IV credential
issuance and native authentication passed; real game launch remains untested.
This does not check paid-game ownership or filter the game catalog by entitlement.

Fixes the uninstall confirmation for games without install-folder user files,
including Hearthstone. The repaired confirmation and Hearthstone move-to-Trash
operation were verified in the installed preview. Existing retention defaults
and uninstall rollback behavior are unchanged.

Apple silicon only, ad-hoc signed and not notarized. Existing app identity,
preferences, external-game locations and Wine support are preserved.
The parked friends experiment is not included.
