# Waypoint 1.2.2-wubs.1

Account labels now use the BattleTag when known, otherwise Account followed by
the existing account ID. Account menus no longer show email subtitles. Email
remains saved for sign-in prefill and optional saved-login management.

This does not add a new profile lookup or force sign-in. Safari-based accounts
may show the fallback label when no BattleTag has been retrieved. Existing
BattleTags and account preferences need no migration.

Retains the previous release’s native and Windows installation support.
Apple silicon only; ad-hoc signed, not notarized; self-update disabled.
