# Waypoint 1.2.4-wubs.1

Adds File → Locate Installed Games… (Command-O). Choose a game folder,
a WoW edition folder, or a folder containing your games, including on an
external drive. Waypoint remembers valid installation roots across restarts.
Reconnect a drive and use Rescan Games if it was unavailable at startup.

Reads existing .product.db and active .build.info metadata without moving,
copying or downloading game files. Copied installs use their current folder;
active edition records retain platform, build and regional identity. Conflicting
build-only regional records are not guessed. Affected running games or downloads
must finish before their location can be changed. Folder selection searches
only immediate game folders, not an entire drive recursively.

Includes the previous BattleTag fix. Apple silicon only; ad-hoc signed,
not notarized. Existing saved accounts and preferences are preserved.
No parked friends/social experiment is included.
