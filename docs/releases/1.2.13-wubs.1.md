# Waypoint 1.2.13-wubs.1

- Settings now has General, Account and Background panes, retaining the fork’s appearance choices and launch-only update controls.
- The Available Games chevron no longer shifts the heading when expanded or collapsed.
- New installations offer Keep Mac awake until the download finishes. The default is on while size is unknown or at least 10 GB; clicking settles your choice. The existing queue persists it across restarts. Updates retain their existing default.
- Drag installed game rows to reorder them. Order is remembered by game UID; Heroes editions share a position. Pending installation rows cannot be dragged.
- The install-size line uses Calculating… instead of a spinner to reduce layout movement. This does not add upstream’s newer free-space validation.

Adapted from upstream 359d3eb, 94acead, b6f55ca, c5172ea and the applicable part of 2a188a7, with Settings checkbox stability from ed66046. Periodic-drive polling changes from bdf8db1 were deliberately excluded. Automatic update checks remain startup plus selected-game launch only.

140 targeted tests and independent source review passed. Native UI validation is performed separately; no real install/download or sleep test is implied by those tests.

Apple silicon only; ad-hoc signed, not notarized. Bundle identity remains io.wubs.waypoint-review. Saved accounts, licence choices, appearance, located folders and notification preferences are preserved. No upstream PR is being submitted for this personal integration.
