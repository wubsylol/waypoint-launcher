# Waypoint 1.2.7-wubs.1

Replaces Select account… with a WoW account submenu containing detected licences,
a checkmark for the selected one, and a separated Refresh list action. Cached
lists survive restarts and are scoped to the Battle.net owner and play region.
Selecting a cached licence does not create another authentication session.

A newly added Americas WoW identity is prompted to choose a default licence.
That default applies to editions without an explicit saved choice; every title
can override it independently. Existing per-title choices are preserved. If
initial selection is cancelled, the next unselected WoW launch asks again.
The normal game-row summary now includes the selected licence beside the
version and effective region.

Refresh uses saved WoW authorization, without a sign-in form or account portal.
It requires WoW closed on all devices; only local clients can be detected.
Failed or cancelled refreshes retain the previous list and choices. A successful
refresh can mark a removed licence unavailable; a launch then asks for another
selection rather than silently switching accounts. Native discovery remains
Americas-only. Other regions retain normal unselected launch behavior, clearing
any stale shared WoW licence value.

The interaction was reviewed against upstream feat/wow-account-selection;
this keeps the personal fork’s native authentication implementation and adds
first-account defaults and visible row selection. No upstream draft PR is
changed by this personal release.

Bundle identifier remains io.wubs.waypoint-review. No preference or Keychain
migration. Apple silicon; ad-hoc signed, not notarized; self-update disabled.
