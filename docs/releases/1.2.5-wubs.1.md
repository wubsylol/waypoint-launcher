# Waypoint 1.2.5-wubs.1

Waypoint now always uses the standard macOS dark appearance, independently
of the system appearance setting. The application-level appearance is set
before its windows are created, including native settings, sheets and panels.
Blizzard controls the content of its sign-in website; Safari retains its own
appearance settings.

Includes external-drive game location and verified BattleTag retrieval.
Apple silicon only; ad-hoc signed, not notarized. Saved accounts, game files
and preferences are preserved. No friends/social experiment is included.
