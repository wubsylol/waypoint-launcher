# Waypoint 1.2.8-wubs.1

Removes Preview from Windows compatibility labels in Available Games,
installation menus, download rows and installed-game details. Titles retain
D3DMetal/Wine or DXMT/Wine labels. This is a presentation change: graphics
backend selection, game availability and internal qualification are unchanged.
Game-specific testing limits remain documented in tools/wine-runtime/WINDOWS-TITLES.md.

Includes 1.2.7 account menus and defaults. Bundle identity remains
io.wubs.waypoint-review; no account, preference or game-data migration.
Apple silicon, ad-hoc signed and not notarized; self-update disabled.
