# Waypoint 1.2.10-wubs.1

- Choose System, Light, or Dark in Settings. The choice applies immediately to native windows and is remembered. This fork keeps its previous Dark default until you choose otherwise.
- Background game update checks refresh the existing off-main installation scan, avoiding stale alerts when another launcher updates or removes a game while Waypoint is inactive. Startup checks wait for any in-progress external-drive scan.
- Retains the menu-bar window toggle, right-click quick actions, opt-in Dock hiding, native login items and native notification delivery feedback from 1.2.9.

Apple silicon only; ad-hoc signed, not notarized. Bundle identity remains io.wubs.waypoint-review. Saved accounts, selected licences and located game folders are preserved. Personal self-update detection remains disabled.
