# Waypoint 1.2.12-wubs.1

- Removed the notification test button and diagnostics UI from Settings. Normal update notifications remain.
- Automatic game version checks now run once when Waypoint starts and for only the selected game when Play is used. No timer, wake or activation-triggered version checks. Launch checks run alongside authentication and cannot delay playing when offline. Manual Check for Updates remains available. Completed downloads clear cached update alerts without another version request.
- The Dock icon and normal app menus appear while the library or Settings is open. With Dock hiding enabled, closing those windows returns Waypoint to menu-only mode. Closing a window still leaves downloads running.
- Finder/Spotlight/manual launches always open the library. Only a recognized login-item launch starts quietly. The Apple-event login hint remains best effort; a real logout/login has not been tested.
- Native notification and login-service status queries now run only on notification opt-in/delivery or while Settings is open. Users who have not enabled notifications do not initialize Notification Center at startup.

Apple silicon only; ad-hoc signed, not notarized. Bundle identity remains io.wubs.waypoint-review. Preferences and accounts are preserved.
