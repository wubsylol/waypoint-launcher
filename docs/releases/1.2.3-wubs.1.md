# Waypoint 1.2.3-wubs.1

Fixes BattleTag retrieval for Safari-based WoW sign-in. The verified native
logon’s profile now flows into the saved Battle.net account during browser
verification and licence selection; no account-management portal is needed.

Native profile retrieval currently uses the Americas service.

For accounts saved by older builds, open the account menu and choose Refresh
BattleTag once with WoW closed on all devices. This uses the saved WoW login,
without a new sign-in form. The name persists across restarts. Missing/invalid
metadata preserves existing names, saved login and licence choices. No native
profile-only connection is started automatically on app launch.

Keeps native and Windows installation support. Does not include the parked
friends/social experiment. Apple silicon only; ad-hoc signed, not notarized;
self-update disabled. Existing bundle identity/preferences are preserved.
