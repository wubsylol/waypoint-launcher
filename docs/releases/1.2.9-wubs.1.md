# Waypoint 1.2.9-wubs.1

- Background update detection for installed games every 30 minutes while Waypoint is running, including menu-bar-only mode and a check after waking. Existing startup/activation checks remain throttled. Checks read version metadata; games are never installed or updated automatically.
- Optional native macOS update notifications, remembered per game build to avoid repeated alerts. Failed or denied delivery can retry. Click a notification to open Waypoint. A Send test notification button reports whether macOS accepted the alert and whether it appeared in Notification Centre; Focus and screen sharing can suppress banners.
- Optional Hide Dock icon mode enables the menu-bar item. Click the icon to toggle the Waypoint window; right-click (or Control-click) for quick actions and Settings. The red close button closes only the window, keeping background work running. Disabling/removing the status item restores the Dock icon.
- Start at login uses macOS Login Items and reflects system approval state. Login launches and menu-only launches do not open the library automatically.
- Settings retain your existing menu-bar preference; notifications and login startup require opting in. Automatic version checks default on. Native integration is disabled in unbundled development runs.

Personal Waypoint self-update checking remains disabled; the existing upstream Sparkle integration is preserved.

Apple silicon only. Ad-hoc signed, not notarized. Bundle identity remains io.wubs.waypoint-review; saved accounts, selected licences, and located external installations are preserved.

Validation: update scheduling, notification deduplication tests, plus account/Windows regressions. See accompanying implementation notes for live UI validation and remaining login-session limits.
