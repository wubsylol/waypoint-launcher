# Waypoint 1.2.0-wubs.1

Local Apple-silicon release of the wubsylol fork. App version 1.2.0, build 6.

## Changes

- Native, owner-verified WoW licence discovery without an account-management portal or second website login.
- Remember a separate licence for each Battle.net identity, WoW edition and region; change it through More → Select account.
- Optional Safari sign-in with a manual, masked browser-return field. Verify the ticket with Blizzard before saving it, including before WoW is installed.
- WoW-first initial authentication for a fresh library. Existing installed-game targeting is retained.
- Clearer official Blizzard sign-in presentation, Retry/Cancel/help controls and bounded connection recovery.
- Available Games remains the install entry point; the redundant toolbar plus button is removed.

## Acceptance

The user confirmed Forever A → B → A licence switching, app-restart persistence, independent Retail/Forever choices, cancellation preserving a choice, and a manually returned Safari ticket reaching character selection. The user then reported the delivered full build worked on a second freshly cleared M5 Pro with no prior Battle.net/WoW setup. The exact login method and restart coverage on that second machine were not separately specified.

110 selected parser, account, native-recovery, launch, installation and metadata tests passed for the preceding test build. Packaging/release checks are recorded with the local artifact. Physical network-loss recovery, a second Battle.net owner, and automatic browser-return handling remain outside the confirmed acceptance.

## Deployment

Apple silicon, declared macOS minimum 14.0. This is a local ad-hoc-signed build, without Developer ID signing or notarization. It includes no Windows runtime or self-update feed. It does not require the official launcher or Xcode on the destination Mac.

The bundle identifier remains `io.wubs.waypoint-review` deliberately: this preserves the preference domain and Keychain service names used by the accepted review build. No credential or licence migration is performed. The app is now named Waypoint.app; quit and replace the old review copy, keeping only one deployed copy of this fork. macOS may request approval to open the app or access existing Keychain entries.

US/Americas is the supported/tested native WoW discovery and Safari-return region. Other game-family embedded sign-in remains available. Safari's localhost restricted-port page is expected for the manual return; copy its address only into Waypoint's masked field. No OAuth client secret is needed by this route. Available Games is a public catalogue, not an entitlement assertion.

No upstream PR or public GitHub Release is created by this local-release workflow.
